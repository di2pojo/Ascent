# Ascent — an AI lab tycoon

A browser game built as a single self-contained HTML file (vanilla JS, three.js for the 3D town). No build step, no backend — saves live in your browser's localStorage.

## Play it locally
Just open `index.html` in a modern browser (Chrome, Firefox, Safari, Edge).

## Deploy
This repo is set up for GitHub Pages: push to `main` and enable Pages (Settings → Pages → Source: `main` / `root`). The site will build automatically at:

`https://<your-username>.github.io/<repo-name>/`
